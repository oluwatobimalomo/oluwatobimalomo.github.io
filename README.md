# Oluwatobi Malomo — academic profile

Static academic and professional profile hosted on GitHub Pages at [oluwatobimalomo.github.io](https://oluwatobimalomo.github.io/).

## Site files

- `index.html` — profile, research overview, selected publications, highlights, and community impact
- `publications.html` — publication list and scholarly profiles
- `experience.html` — research and work experience, education, teaching, service, and awards
- `news.html` and `news.js` — recent highlights
- `blog.html` — selected external writing
- `assets/css/style.css` — shared site styles
- `assets/docs/Oluwatobi_Malomo.pdf` — downloadable CV
- `assets/img/` — profile and other images

This repository is currently plain HTML, CSS, and JavaScript. GitHub Pages serves the files directly; there is no Jekyll configuration or build step in this checkout.

## Updating content

Update publication details consistently in both `index.html` and `publications.html`. Keep links and publication status current in `news.js`. Update the CV file and its links together if its filename changes. The sitemap is in `sitemap.xml`.
